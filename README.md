🛒 Pick 'N' Mix - Grocery Management Store
Pick 'N' Mix is an online grocery management store where users can browse, filter, and purchase groceries. The project includes both a user-facing frontend and an admin panel for managing products, orders, and users.

✨ Features
👤 User Side (Frontend):
Product Categories: Browse products by category.

Product Search and Filters: Search for products by name.

Product Details: View detailed product information such as name, price, and description.

Add to Cart: Add products to the cart, and update quantities or remove items.

Checkout Process: Fill in shipping details, calculate the total amount, and place an order.

Order History: View previous orders and their statuses.

🧑‍💼 Admin Side (Admin Panel):
Admin Authentication: Secure login for admins.

Product Management: Add, edit, or delete products and categories.

Order Management: View and update customer orders (e.g., mark as shipped or delivered).

User Management: View and manage user accounts.

Image Upload: Upload product images directly from the admin panel.

🧰 Tech Stack

Component	Technology

Backend	PHP (REST APIs)
